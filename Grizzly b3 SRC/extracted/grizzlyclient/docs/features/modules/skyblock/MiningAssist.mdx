# Mining Assist

Maintains breaking progress and shows whether the targeted block is in reach.

---

The module highlights the block under your crosshair and shows its current
breaking percentage in the modules list.

### Maintain breaking progress

Continues Minecraft's normal block-breaking action while the attack key is held
and the block is within the configured reach.

### Reach indicator distance

Sets the distance used to decide whether the targeted block is in reach.

### In reach color

Sets the highlight colour for blocks inside the configured reach.

### Out of reach color

Sets the highlight colour for blocks outside the configured reach.
