# Efficient Miner Overlay

Predicts the Mining Spread pattern around the block under your crosshair.

---

The targeted block and nearby blocks that may be mined by Mining Spread are
highlighted before you begin breaking the block.

### Blocks

Controls which blocks can activate the prediction and be included in the spread.

### Spread blocks

Sets the maximum number of adjacent blocks included in the prediction.

### Show bedrock risk

Highlights adjacent bedrock so you can avoid Mining Spread patterns that may
reach it.

### Target color

Sets the colour used for the block under your crosshair.

### Spread color

Sets the colour used for predicted Mining Spread blocks.

### Bedrock risk color

Sets the colour used for adjacent bedrock.
