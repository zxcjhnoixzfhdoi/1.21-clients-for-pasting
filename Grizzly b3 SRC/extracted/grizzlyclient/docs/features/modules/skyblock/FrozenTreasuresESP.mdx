# Frozen Treasures ESP

Highlights frozen treasure drops on the Glacial Cave floor.

---

The module detects supported frozen treasures from their displayed item,
including gifts, ice drops, bait, Glacial Fragments, and the Glacial Talisman.

### Color

Sets the colour used to highlight frozen treasures.
