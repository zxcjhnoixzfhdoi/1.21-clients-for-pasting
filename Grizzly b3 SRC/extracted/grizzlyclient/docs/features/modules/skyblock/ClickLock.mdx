# Click Lock

Holds the mining button until its toggle key is pressed again.

---

Click Lock uses Minecraft's normal attack key state, so mining continues as if
the button were being held physically.

### Toggle key

Toggles Click Lock without enabling or disabling the module. Mouse side buttons
are supported.

### Release in menus

Temporarily releases the mining button while a screen or menu is open.

Click Lock also pauses automatically while **Auto Pickaxe Ability** performs its
slot swaps and resumes afterward.
