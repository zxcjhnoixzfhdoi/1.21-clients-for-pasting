# Mineshaft Ore Guide

Colour-codes Umber and Tungsten blocks by their mining yield.

---

### Range

Sets the horizontal distance around the player that is searched for ore blocks.

### Vertical range

Sets how far above and below the player the module searches.

### Only in mineshafts

Only renders ore highlights while you are in a Glacite Mineshaft.

### Show low yield

Also highlights low-yield Tungsten cobblestone and Umber orange terracotta.

### Tungsten clay

Sets the colour used for high-yield Tungsten clay.

### Tungsten cobblestone

Sets the colour used for low-yield Tungsten cobblestone.

### Umber red sand

Sets the colour used for high-yield Umber red sand.

### Umber dark terracotta

Sets the colour used for medium-yield Umber terracotta.

### Umber orange terracotta

Sets the colour used for low-yield Umber orange terracotta.
