# Corpse Finder

Highlights corpses and Littlefoot in Glacite Mineshafts.

---

### Only in mineshafts

Only searches for corpses and Littlefoot while you are in a Glacite Mineshaft.

### Lapis corpses

Highlights Lapis corpses.

### Tungsten corpses

Highlights Tungsten corpses.

### Umber corpses

Highlights Umber corpses.

### Vanguard corpses

Highlights Vanguard corpses.

### Littlefoot

Highlights entities named Littlefoot.

### Announce discoveries

Shows a message with the coordinates when a corpse or Littlefoot is found.

### Corpse colours

Sets a separate highlight colour for Lapis, Tungsten, Umber, and Vanguard corpses.

### Littlefoot colour

Sets the colour used to highlight Littlefoot.
