# Dance Room Helper

Automatically performs the actions required by the Mirrorverse dance room.

---

The current instruction sequence is downloaded from SkyHanni each time the
module is enabled. An internet connection is required.

Leaving the room or disabling the module cancels pending actions and restores
the physical keyboard state.

### Early offset ms

Sets how many milliseconds before the next one-second dance cue the action is
performed. The default is 50 milliseconds.

### Key press ms

Sets how many milliseconds move, sneak, and jump inputs remain pressed. Stand
instructions release sneak immediately.
