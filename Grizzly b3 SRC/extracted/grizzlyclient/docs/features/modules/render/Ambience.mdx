# Ambience

Changes the world appearance properties.

---

### Real World Time

Follow your computer's clock instead of a fixed time. Real midnight maps to in-game midnight and
real noon to in-game noon, so the sky tracks the actual time of day.

### Time

The tick to hold the world at when **Real World Time** is off. `0` is sunrise, `6000` is noon,
`12000` is sunset, and `18000` is midnight.
