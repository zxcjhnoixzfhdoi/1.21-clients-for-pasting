# Step <sup><Chip label="Warning" color="warning" size="small" component="a" href="/guides/anticheat-safety#risk-labels" icon={<WarningIcon />}/></sup>

Allows you to walk up blocks taller than Minecraft's normal step height.

---

### Mode

- **VANILLA**: raises the player's native step height without additional packets
- **NCP**: for NoCheatPlus
- **OLD NCP**: for older versions of NoCheatPlus

### Height

Maximum height that can be stepped up.

### Delay

Minimum delay in milliseconds between confirmed steps.
