### Mode

Which technique to use. All three need you to walk into the block you want to pass through, so
none of them do anything while you are standing still.

- **VANILLA**

- **NCP**

- **NORULES**

### NoRules offset

How far behind your real position the server is told you are.

### NoRules delay (ms)

Minimum time between shoves.
