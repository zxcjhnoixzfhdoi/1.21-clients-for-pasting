# Block In

Builds a nine-block enclosure around your feet, body, and head.

Enabling Block In only arms the module. Press **Activate key** to start an enclosure pass; press it again to cancel. The module restores your previous hotbar slot when it finishes or is cancelled.

---

### Activate key

The secondary keybind that starts or cancels blocking in. This is separate from the module's enable keybind.

### Rotation speed

Controls how quickly the server-side placement rotation moves.

### Randomization

Varies rotation speed slightly between ticks.

### Rotation tolerance

Limits how far the current rotation may be from the planned placement before the block can be placed.

### Ignore blocks

Prevents selected block types from being used. Configure them with **Ignored blocks**.
