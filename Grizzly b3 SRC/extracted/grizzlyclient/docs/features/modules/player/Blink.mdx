# Blink

Buffers outgoing packets, making you appear frozen to the server

---

### Hold (ms)

Duration to hold outgoing packets before releasing them.

### Packet limit

Automatically disables Blink when the buffered packet count reaches the configured maximum.

### Max packets

Maximum number of packets to buffer before Blink disables. Only shown when Packet limit is enabled.

### Show ghost

Render a ghost preview of your frozen position while blinking.
