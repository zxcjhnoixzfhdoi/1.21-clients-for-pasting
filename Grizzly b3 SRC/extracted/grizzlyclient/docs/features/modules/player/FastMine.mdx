# Fast Mine

Reduces the delay between mined blocks and increases block-breaking speed.

:::warning
Faster mining can be detected by servers. Keep the speed and delay appropriate for the server you are playing on.
:::

---

### Break delay (ms)

Controls the delay before another block can begin breaking. Vanilla uses 250 ms.

### Break speed

Multiplies vanilla block-breaking progress from 1x to 2x.

### Disable in creative

Leaves creative-mode mining unchanged.

### Decrease break delay

Passively reduces a stale mining delay when the client does not advance it normally.
