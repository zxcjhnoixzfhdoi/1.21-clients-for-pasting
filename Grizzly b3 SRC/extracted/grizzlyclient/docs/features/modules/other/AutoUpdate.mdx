# Auto Update

Keeps the client up to date with the latest build from your chosen channel.
Disable the module to disable auto updating.

---

### Channel

- **BETA**: the newest artifact from a CI build of a branch
- **RELEASE**: the jar attached to the newest release

### Install automatically

On by default. Turn it off to be told an update exists without downloading it.

### Notify

Show a toast when an update is downloaded, or when one is found and installing is off.

### Check now

Checks immediately instead of waiting for the next launch, and reports what it found either way.
