# Target Filter

Filters targets across combat modules (anti-bot, teams, etc)

---

### Ignore team

Ignore entities on the same team as the player.

### Ignore color

Ignore players with the same dyed armor color.

### Ignore invisible

Filter out invisible entities.

### Anti-bot

Enable additional target validation for player entities.

#### Anti-bot mode

Which set of checks to run. Both only ever apply to players, never to mobs.

- **SMART**: works on most servers, like Hypixel.

- **MATRIX**: from Matrix.
