# Commands

Client-side `,` commands and public `!` chat commands

For the full command list and examples, see the
[Commands guide](../../../guides/commands.mdx).

### Public commands

Master switch for the public command system. When enabled, anyone in your chat
can trigger commands such as `!ping`, `!tps`, or `!help`, and the client replies
with a regular chat message.

### Command prefix

The prefix used for public commands (default `!`). Changing it updates autofill
and chat detection automatically.

### Client prefix

The prefix used for client-side commands (default `,`). Changing it updates
autofill and chat interception automatically.

### Party/Guild only

When enabled, public commands only work while on Hypixel, and only when they are
sent in party or guild chat.
