# BedPlates

Displays what blocks are defending a bed, letting you either find the weakest bed defenses, or plan what tools you need to bring. Useful for the Bed Wars minigame.

---

### Font

Font used for this element's text. **DEFAULT** follows the client font set in **Font**, and any
other choice overrides it for this element only.

### Render Layer

Where the plates are drawn relative to the rest of the HUD.

### Search Range

How far away (in blocks) to scan for beds.

### Shell Radius

How many blocks out from the bed to check for defense blocks.

### Scan Interval

How frequently (in milliseconds) to re-scan for beds and their defenses.

### Background Mode

- **SOLID**: use the configured background color
- **BLUR**: blur the gameplay behind each bed plate and tint it with **BG Color**

### Blur Strength

Controls the Gaussian blur radius when **Background Mode** is **BLUR**.

### BG Color

Background color for each bed plate. Its alpha controls tint strength in blur mode.

### Drop Shadow

Draw a GPU-rendered soft shadow behind every visible bed plate. Configure its color and opacity, softness, spread, and X/Y offset.

### Show Distance

Show the live distance above each bed's defense icons. Beds without detected defenses are not rendered when this is disabled.

### Use Bed Color

Color the distance using the bed's dye color.

### Text Color

Custom color for the distance text when **Use Bed Color** is disabled.
