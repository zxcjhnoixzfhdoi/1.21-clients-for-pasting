# Block Counter

Displays hotbar block count for the item in hand

---

### Font

Font used for this element's text. **DEFAULT** follows the client font set in **Font**, and any
other choice overrides it for this element only.

### BG color

Background color for the info box, with alpha support. Its alpha controls tint strength in blur mode.

### Background mode

- **SOLID**: use the configured background color
- **BLUR**: blur the gameplay behind the counter and tint it with **BG color**

### Blur strength

Controls the Gaussian blur radius when **Background mode** is **BLUR**.

### Drop shadow

Draw a GPU-rendered soft shadow behind the counter. Configure its color and opacity, softness, spread, and X/Y offset.

### Text color

Text color used for the block count.

### Only on scaffold

Only show the counter while scaffold or clutch is active.
